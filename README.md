# CV Flutter - TP2 - Miriam Zawadi
ISIG - Licence 3 - Langage de Programmation Mobile

Application Flutter connectée à une API REST PHP / MySQL.
Flutter -> HTTP -> API PHP -> MySQL

## Fonctionnalités
- Connexion réelle via POST /accounts/login
- Liste famille depuis GET /famille-membres
- Ajouter, Modifier, Supprimer via API

## Lancer
flutter pub add http
flutter analyze
flutter run -d windows

API : http://localhost/api-test/public
